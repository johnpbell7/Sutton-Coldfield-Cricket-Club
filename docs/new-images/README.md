# Drop new archive images here

Upload photographs, documents and scans into this folder and they will be
added to the site.

## How to upload from a browser

1. Go to <https://github.com/johnpbell7/Sutton-Coldfield-Cricket-Club>
2. Open the **docs** folder, then this **new-images** folder
3. **Add file → Upload files**
4. Drag the images in
5. Scroll down and press **Commit changes** (leave it committing to `main`)

Any filename will do. Where the date, the occasion or the people in a
photograph are known, put them in the commit message or say so in chat and
they will go into the caption.

Images are moved out of this folder into `src/assets/decades/<decade>/` once
they have been placed on the site, so an empty folder means everything sent
so far has been used.
